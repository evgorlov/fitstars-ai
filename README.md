# FitStars AI · материалы в фирменном стиле

Набор скиллов отдела дизайна. Каждый скилл — один файл с правилами.
Чтобы им воспользоваться, не надо ничего ставить: открой Claude, дай ссылку
на нужный скилл и свой бриф.

## Скиллы

| Что собираем | Ссылка на скилл |
|---|---|
| **Презентация** | https://raw.githubusercontent.com/evgorlov/fitstars-ai/main/skills/deck.md |
| Лендинг | в работе |
| Креатив | в работе |

## Как пользоваться

Вставь в Claude сообщение вида:

> Собери презентацию по этому скиллу: https://raw.githubusercontent.com/evgorlov/fitstars-ai/main/skills/deck.md
>
> Бриф: [дальше твой бриф — текст, документ или расшифровка звонка]

Claude прочитает файл по ссылке и соберёт деку по правилам: фирменная сетка,
палитра, типографика, иконки и маскот из библиотеки. На выходе HTML —
открывается в браузере, печатается в PDF через Cmd+P.

## Библиотека

`assets/` — то, на что ссылаются скиллы: иконки, маскот, шрифт, логотип.
Адреса вида `https://raw.githubusercontent.com/evgorlov/fitstars-ai/main/assets/...`
подставляются прямо в вёрстку, поэтому материал выглядит одинаково у всех.

## Откуда это берётся

Источник — рабочий репозиторий проекта. Здесь лежит собранная копия.
Править надо источник и пересобирать: `bash tools/build-public.sh`.
